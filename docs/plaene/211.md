## Ziel

Am Handy erfasst Tim eine neue Tüte mit der Kamera in drei Schritten (Vorderseite, Rückseite, Ergebnis der KI). Erkennt die KI eine vorhandene Sorte, fügt ein Tipp die Packung hinzu, sonst entsteht eine neue Sorte und die Recherche startet von selbst. Mit «Fotos nachtragen» fotografiert er nacheinander die Tüten aller Sorten ohne Foto («3 von 22: Genoveser»). Die Liste «Saatgut» zeigt die Sorten nach Gemüse gruppiert mit Tütenbild und Status als Wort, filterbar nach «Vorrätig» und «Ohne Foto».

## Domäne und Datenfluss (Signaturen)

**`src/domain/sorten/saatgut.ts`** (rein, G1; keine Zeit):
- `type SaatgutStatus = 'vollständig' | 'Recherche offen'`.
- `interface SaatgutZeile { sorteId; name; artId; artName; vollstaendig: boolean; status: SaatgutStatus; ohneFoto: boolean; fotoPfad?: string }`.
- `saatgutListe(t: Teile): SaatgutZeile[]`: je gültige Sorte aus `sortenListe(t)` (Name, `artName` = `art.name_de`, sonst `art_id`; `vollstaendig` aus `v_vollstaendigkeit`), dazu `aktuelleTuetenfotos(t['tuetenfoto'], sorteId)`: `ohneFoto` = weder `vorne` noch `hinten`; `fotoPfad` = Pfad der Vorderseite, sonst der Rückseite. `status` = «vollständig» bei `vollstaendig`, sonst «Recherche offen» (auch ohne Zeile in `v_vollstaendigkeit`). Reihenfolge: nach `artName`, dann `name`, je `localeCompare(…, 'de-CH')`. Das ist die «Listenreihenfolge» für SG1-AK2.
- `type SaatgutFilter = 'vorraetig' | 'ohne_foto'`. «Vorrätig» = alle gültigen Sorten, bis N3 «aufgebraucht» bringt (A5).
- `saatgutGruppen(liste: readonly SaatgutZeile[], filter: SaatgutFilter): { gemuese: string; sorten: SaatgutZeile[] }[]`: gefiltert, gruppiert nach `artName`, Gruppen de-CH alphabetisch, in der Gruppe nach Name; leere Gruppen fallen weg.
- `saatgutZahlen(liste): { vorraetig: number; ohneFoto: number }`.
- `interface NachtragEintrag { sorteId; name; artName }`.
- `nachtragReihe(liste): NachtragEintrag[]` = die Sorten mit `ohneFoto` in Listenreihenfolge.
- `interface NachtragStand { reihe: readonly NachtragEintrag[]; index: number; ergaenzt: number; uebersprungen: number }`.
- `nachtragStarten(liste): NachtragStand`: Schnappschuss der Reihe, `index` 0, beide Zähler 0. Spätere Bündel ändern den Stand nicht.
- `nachtragWeiter(stand, wie: 'ergaenzt' | 'uebersprungen'): NachtragStand`: Zähler plus 1, `index` plus 1; nach dem Ende unverändert.
- `nachtragPosition(stand): { fertig: false; nummer: number; gesamt: number; eintrag: NachtragEintrag } | { fertig: true; ergaenzt: number; uebersprungen: number }`: `nummer` = `index + 1`, `gesamt` = Länge der Reihe. Leere Reihe → sofort `fertig` mit 0 und 0.

**`src/domain/sorten/erfassung.ts`** (Ergänzung):
- `sortennameNormalisieren(name: string): string`: Kleinbuchstaben (`toLocaleLowerCase('de-CH')`); Anführungszeichen und Apostrophe `' " « » ‹ › „ “ ” ‘ ’ ‚ \`` entfallen ohne Ersatz; übrige Satzzeichen `. , ; : ! ? ( ) [ ] / - – —` werden zu Leerzeichen; Leerraum zusammengefasst und getrimmt (A12). Beispiel: «‹BULL’S  BLOOD›» und «Bull's Blood» → «bulls blood»; «Babyleaf-Mischung» und «Babyleaf Mischung» → «babyleaf mischung».
- `vorhandeneSorte(sorten, name, artId)`: vergleicht neu über `sortennameNormalisieren()`; Rest unverändert (gilt damit auch in «Von Hand erfassen»).
- `sorteErkennen(sorten: readonly SorteZeile[], arten: readonly ArtZeile[], felder: { name?: string | null; art?: string | null }): { sorteId: string; artId: string } | undefined`: Art über `artVorschlagen(arten, felder.art)`; ohne Art oder ohne Name `undefined`; sonst `vorhandeneSorte(sorten, name, artId)` (nur gültige Sorten derselben Art).
- `kulturtypVorschlagen(sorten: readonly SorteZeile[], artId: string | undefined): Kulturtyp | undefined`: häufigster `kulturtyp` der gültigen Sorten derselben Art; Gleichstand in der Folge Blatt, Knolle, Frucht (A13); ohne Sorte `undefined`.
- `SorteZeile` erhält `kulturtyp?: string | null` (Spalte aus dem Bündel `sorte`).
- `erfassungBauen()` bleibt unverändert: Ohne Eingabe im Feld `bestandKorn` schreibt es `bestand_korn: null` (A7). `formularPruefen()` behält die Prüfung des Felds.

**Oberfläche, Hilfen (`src/ui/saatgutSpeichern.ts`, A10):**
- `tuetenfotoHochladen(ordner: string, datei: File): Promise<{ pfad: string } | { fehler: 'lesbar' | 'hochladen' }>` = `tuetenbildVerkleinern()` plus `fotoHochladen()`; Nutzer: `SorteNeu`, `TuetenfotoKarte`, `SaatgutErfassen`, `SaatgutNachtragen`.
- `interface Speicherstand { schluessel: string; wissen: WissenAufruf[]; vorgang: Vorgang; wissenErledigt: number }` und `erfassungSenden(stand): Promise<{ status: 'gespeichert'; stand } | { status: 'nicht_gespeichert'; stand; meldung: string }>`: `wissenSchreiben(stand.wissen, stand.wissenErledigt)`, danach `schreiben(stand.vorgang)`; bei «abweichend» die Meldung aus `SorteNeu` («Nicht gespeichert: Diese Packung ist schon mit anderen Angaben gespeichert.»). Wiederholen setzt beim ersten offenen Schritt fort (Plan 37 A14, TO2).

**Datenfluss.** Liste: Bündel (`sorte`, `art`, `v_vollstaendigkeit`, `tuetenfoto`) → `saatgutListe()` → `saatgutGruppen()` / `saatgutZahlen()` → `SaatgutEintrag` → `fotoLink(fotoPfad)` (online) → `Sortenzeile`. Tüte erfassen: Fotos → `tuetenfotoHochladen(ids.sorteId, …)` → `tueteLesen({ fotopfade })` → `formularNachKi()` → `artVorschlagen()` / `sorteErkennen()` / `kulturtypVorschlagen()` → Tim → `erfassungBauen()` → `erfassungSenden()` → bei neuer Sorte `rechercheStarten()`.
