## `scripts/demo.ts`

- `benoetigteSorten(fixtures): string[]` (rein, in `scripts/demo/regeln.ts`): alle Werte `?sorte_schluessel.sorte_key=<key>` der Fixtures.
- `wissenSichern(abfrage, fixtures)`: Abfrage der aktiven Sorten (`sorte.gueltig_bis is null` über `sorte_schluessel`) für genau diese Schlüssel.
  - alle da → weiter;
  - Wissen leer (keine aktive Sorte) und Ziel `lokal` → `npm run seed -- --ziel lokal` (echtes W0 aus der Wurzel), danach erneut prüfen;
  - sonst Abbruch mit Liste der fehlenden Schlüssel und Hinweis «zuerst `npm run seed -- --ziel lokal` bzw. dev-seed scharf» (A6). In dev lädt `demo` nie selbst Wissen (der Workflow ruft den Seed vorher auf).
- Der bisherige Abbruch «Wissen enthält andere Sorten» entfällt; vorhandenes Wissen wird nie überschrieben.
