## Ziel

Der Düngerrechner steht als reine, getestete Rechenlogik in `src/domain/`: Neuansatz mit Skalierung auf das innere Band, Kappung und Teil-Dosis, Stationen mit fester Dosis, Herstellerstadium für Direktsaat und Station, Restdosis mit kIst und k-Vorschlag, Teilwechsel und «möglicherweise doppelt dosiert», Nachfüllen, Verdünnen und Kratky-Nachfüllen, Rundung in Tims Messmitteln. Er trifft jede Zeile der Referenzdatei auf ±0.5 ml und hält im Mutationstest mindestens 80 %. Am Gerät ist nach diesem Paket noch nichts Neues sichtbar; die Abhakliste I1b-04 baut darauf auf (A1).

## Einheiten und Signaturen

**Einheiten (G3).** Alle Ein- und Ausgaben sind Ganzzahlen: EC in Hundertsteln mS/cm (`Hundertstel` aus `bewertung.ts`), k in Tausendsteln mS/cm je ml/L (wie `k_faktor.wert numeric(4,3)`), Dosis in Hundertsteln ml/L (wie `duengerschema`), Volumen in Hundertsteln l (wie `betriebsvolumen_l`), Mengen als Ergebnis in Zehnteln ml, Liter als Ergebnis (Teilwechsel, Verdünnen, Kratky) in Zehnteln l (A11), Teil-Dosis in Prozent (75, 85, 100). Zwischenwerte sind exakte Brüche aus Ganzzahlen; gerundet wird genau einmal am Ende (A3). Grund: Die AK hängen an exakten halben Schritten (RF8 1.15 → 1.2, RF10 2.25 → 2.3 und 0.75 → 0.8, RF11 7.25 → 7.5, UC7-AK1 Micro 75 % = 7/3 · 1/3 · 9 · 0.75 = 5.25 → 5.5), die mit Gleitkomma kippen.

**Komponenten.** `Komponente` und `KOMPONENTEN` aus `einstellungen.ts` (`grow`, `micro_hard_water`, `bloom` = `produkt.produkt_id`). `Dosis = Readonly<Record<Komponente, number>>` (Hundertstel ml/L), `KSatz = Readonly<Record<Komponente, number>>` (Tausendstel), `Mengen = Readonly<Record<Komponente, number>>` (Zehntel ml). `Zielbereich = { min: Hundertstel; max: Hundertstel }`. `Stadium` = Enum `stadium` ohne `reife` (R4.3: «Reife» wird nie verwendet).

**Hinweise.** `RechnerHinweis = { code: HinweisCode; text: string }`; Codes: `ziel_nicht_erreichbar`, `wasser_zu_hoch_fuer_gefaess`, `untergrenze_wasser`, `wasser_hoch` (ab 1.0), `messgeraet_oder_wasser_pruefen`, `kalibrierung_pruefen`, `ueber_herstellerdosis`, `restdosis_null`, `doppelt_dosiert`, `mehr_ec_als_erwartet`, `nur_wasser`, `kein_verduennen_noetig`, `verduennen_unmoeglich`, `verduennen_gekappt`, `eingabe_noetig`. Texte wörtlich aus Konzept und UC7, wo vorhanden.

### `rechner-zahlen.ts`

- `rundeMenge(roh: Bruch): number` → Zehntel ml. Roh unter 5 ml auf 0.1 ml, sonst auf 0.5 ml, halb aufwärts; die Schwelle «unter 5 ml» gilt für den ungerundeten Wert (R4.11, G4; Entwurf Annahme 9). Roh > 0 ergibt mindestens 0.1 ml (R4.4 «keine Komponente auf 0», A4); roh = 0 bleibt 0; negativ ist ausgeschlossen (Fehler im Aufrufer).
- `messmittel(zehntelMl: number, spritzen?: readonly number[]): Messmittel` mit `Messmittel = { spritzeMl: number | null; aufzuege: number; text: string }`. Standard `[1, 5, 20, 60]` (Konzept 5.6); kleinste Spritze, die die Menge in einem Aufzug fasst (Grenzen eingeschlossen); über 60 ml die 60-ml-Spritze mit ⌈ml / 60⌉ Aufzügen bis 3; darüber `spritzeMl = null` und «Messbecher» (`01_fachregeln.md` R4.11). Die Liste aus `einstellung.messmittel` darf übergeben werden (A5).
- `rundungsabweichungEc(roh: Mengen-Bruch, gerundet: Mengen, k: KSatz, volumen: number): Hundertstel` = Σ k_i · (gerundet_i − roh_i) / V, auf Hundertstel kaufmännisch nach Betrag mit Vorzeichen (RF1: −0.133 ml auf 7 l → −0.0057 → −0.01).
- `mlText(zehntel)`, `ecText(hundertstel, { vorzeichen })`, `literText(zehntel)`.

### `rechner.ts`

- `HERSTELLERDOSIS: Readonly<Record<Stadium, Dosis>>` mit den Werten aus R4.3 und Düngeplan Abschnitt 2 (wurzeln_keimung 50/50/50, echte_blaetter 100/100/100, wachstum 180/120/60, vorbluete 200/200/150, bluete_frucht 80/160/240). Die App liest später `duengerschema`; die Funktionen erhalten die Dosis deshalb als Parameter, die Konstante dient Tests und als Rückfall (A6).
- `kWirksam(k: KSatz, dosis: Dosis): Bruch` = Σ k_i · d_i / D (R4.1, Anteile des Stadiums; abweichend von `einstellungen.kWirksam`, das fest mit den Anteilen von Wachstum rechnet, A7).
- `inneresBand(zb: Zielbereich): { unten: Bruch; oben: Bruch }` = [u + ¼ · (o − u), o − ¼ · (o − u)], Grenzen eingeschlossen (R4.2; RF2 1.575 bis 1.725 exakt).
- `ecWasser(e: { frischwasser?: Hundertstel; letzteW?: Hundertstel }): { wert: Hundertstel; quelle: 'frischwasser' | 'w' | 'annahme'; hinweise }` (R4.1, R4.6 Zeile 3): Frischwasser ausserhalb 0.20 bis 1.00 → letzter W-Wert und «Messgerät oder Wasser prüfen»; Abweichung über 0.15 zum letzten W-Wert → «Kalibrierung prüfen»; ohne beides 0.50; Wert ab 1.00 → Warnung `wasser_hoch` (UC7 Varianten).
- `zielEc(e: { zielbereich: Zielbereich; ecSoll: Bruch; ecWasser: Hundertstel }): { ecZiel: Bruch; skalieren: boolean; hinweise }` (R4.2). Reihenfolge (A8): 1. ECWasser > o − 0.30 → ECZiel = o, `skalieren`, Hinweis «Leitungswasser zu hoch für dieses Gefäss». 2. ECSoll im inneren Band → ECZiel = ECSoll, nicht skalieren. 3. Sonst ECZiel = Bandmitte, angehoben auf ECWasser + 0.30 (Hinweis `untergrenze_wasser`), höchstens o.
- `neuansatz(e: NeuansatzEingabe): NeuansatzErgebnis | EingabeNoetig` (R4.1, R4.2, R4.4, R4.5, R4.7 Teil-Dosis, R4.11).
  - `NeuansatzEingabe = { volumen; stadium?; dosis?; zielbereich?; zielEcGewaehlt?; ecWasser; k; teilDosis: 75 | 85 | 100; istStation; ueberHerstellerdosisBestaetigt }`.
  - Ohne Stadium oder ohne Zielbereich und ohne `zielEcGewaehlt` (leeres Gefäss, R2.2 «niemand zählt») → `{ art: 'eingabe_noetig', felder: ['ziel_ec', 'stadium'], vorschlagStadium: 'wachstum' }` ohne Rechnung (RF7).
  - Station (`istStation`): feste Dosis des Stadiums, keine Skalierung, Teil-Dosis wird ignoriert (100 %), ECZiel = ECSoll der festen Dosis, Kontrollband nach R4.5 (RF8, UC7-AK7).
  - Sonst ECSoll = ECWasser + Σ k_i · d_i; `zielEc`; bei Skalierung D_neu = D · (ECZiel − ECWasser) / (ECSoll − ECWasser), exakt als Bruch. Mit `zielEcGewaehlt` ohne Zielbereich wird direkt auf diesen Wert skaliert, mindestens ECWasser + 0.30 (A9).
  - Kappung R4.4: D_neu > min(5.5, 1.2 · D) → ohne Bestätigung D_neu = Grenze, ECZiel = ECWasser + Σ k_i · d_i(gekappt), `gekappt = true`, Hinweis «Ziel nicht ganz erreichbar»; mit `ueberHerstellerdosisBestaetigt` keine Kappung, Hinweis `ueber_herstellerdosis` und `kontrolleFolgetag = true` (UC7-AK13).
  - `NeuansatzErgebnis = { art: 'ergebnis'; stadium; dosisHersteller; dosisVerwendet (Hundertstel ml/L, nur zum Speichern gerundet); ecSoll; ecZiel (Hundertstel); skaliert; gekappt; kontrolleFolgetag; teilDosis; mengen (100 %); mengenTeil (mit Teil-Dosis); messmittel je Komponente; ecErwartetTeil (Hundertstel, aus den gerundeten Teil-Mengen); rundungsabweichungEc; kontrollband?; hinweise }`.
  - Mengen roh = D_neu · a_i · V · Teil-Dosis aus dem ungerundeten Bruch, nie aus `dosisVerwendet` (Risiko 2).
- `stationsDosis(stadium: 'wurzeln_keimung' | 'echte_blaetter'): Dosis` und `kontrollband(stadium, ecWasser): Zielbereich` (R4.5: + 0.30 bis + 0.60; + 0.80 bis + 1.20).
- `herstellerstadium(e: StadiumEingabe, jetzt: Date, zeitzone: Zeitzone): Stadium | 'anfeuchten'` (R4.3), nur aus fertig ermittelten Eingaben: `{ ort: 'anzuchtbox' } | { ort: 'station'; aeltesterEintrittAm: Date } | { ort: 'zielgefaess'; direktsaat: boolean; phaseLeitkultur: Phase; umgesetztAm?: Date }`. Tage als Kalendertage in Zürich (G2). Anzuchtbox → `anfeuchten` (0.1 ml/L je Teil); Station Tag 0 bis 14 → wurzeln_keimung, ab Tag 15 echte_blaetter; Direktsaat → wachstum ab dem Saattag; Zielgefäss Tag 0 bis 7 nach dem Umsetzen → echte_blaetter; danach anzucht → echte_blaetter, wachstum → wachstum, bluete → vorbluete, fruchtbildung_reife → bluete_frucht. Die Wahl der Leitkultur (R2.3) und der zählenden Pflanzungen (R2.2) bleibt bei I2-02 (A10).

### `rechner-korrektur.ts`

- `ecSollIst(e: { ist: Mengen; volumen; k; ecWasser }): { exakt: Bruch; gerundet: Hundertstel; istDosis: Bruch }` = ECWasser + Σ k_i · ist_i / V; gerundet auf Hundertstel (R4.8, E-F4-9).
- `restdosis(e: { ecZiel: Bruch; ecIst: Hundertstel; ecWasser; ist: Mengen; volumen; k; dosis (Anteile des Stadiums); grenzeGesamt? }): RestdosisErgebnis` (R4.7): ΔD = (ECZiel − ECIst) / k_wirksam (Einstellung, nicht kIst); ECIst ≥ ECZiel → alle Mengen 0, bei ECIst > ECZiel Hinweis `restdosis_null` (RF9); sonst ΔD · V im Verhältnis des Stadiums, gerundet nach R4.11; Ist-Dosis plus ΔD höchstens bis zur Grenze R4.4 (A12). Ausgabe zusätzlich `ecSollIst`, `abweichung` (|ECIst − ECSoll_ist| in Hundertsteln), `kIst` (Tausendstel, nur Anzeige).
- `doppeltDosiert(e: { kontrolle: Hundertstel; ecSollIstTeil: Hundertstel; teilwechsel: TeilwechselEingabe }): { hinweis: boolean; angebot?: Teilwechsel }` (R4.8): Hinweis, wenn Kontrolle > gerundete erwartete Teil-EC + 0.25 (RF12: 1.04, Grenze 1.29, Hinweis ab 1.30); mit dem Teilwechsel als Angebot.
- `teilwechsel(e: { volumen; ecIst; ecZiel; ecWasser }): { art: 'absaugen'; liter: number; text } | { art: 'nicht_noetig' }` (R4.8): V_ab = V · (ECIst − ECZiel) / (ECIst − ECWasser), auf 0.1 l (A11); ECIst ≤ ECZiel → nicht nötig, ohne Division. UC7-AK14: 2.7 l.
- `kVorschlag(e: { kontrolle: Hundertstel; ecSollIstKontrolle: Hundertstel; istDosis: Bruch; endmessung?: Hundertstel; ecSollIstGesamt: Hundertstel; ecWasser; k: KSatz; dosis; uEc: Hundertstel; unsicher: boolean; datenart: Datenart }): KVorschlag` mit `KVorschlag = { art: 'kein'; grund: 'abweichung_klein' | 'unsicher' | 'nicht_echt' | 'endmessung_fehlt' } | { art: 'banner' } | { art: 'vorschlag'; kNeu: KSatz; kIst; rueckfrage: boolean; uebernehmbar: boolean }` (R4.7, R4.1, G5): Banner «Mehr EC als erwartet: Dosis, Volumen oder Kanne prüfen», wenn Endmessung > ECSoll_ist(gesamt) + 0.30, dann kein Vorschlag (UC7-AK15); Vorschlag nur bei |Kontrolle − ECSoll_ist| > u_EC, nie aus «unsicher», nur `echt`; kNeu_i = k_i · kIst / k_wirksam auf Tausendstel; `uebernehmbar` = 0.20 ≤ k_wirksam(neu) ≤ 0.45, `rueckfrage` = Änderung über 20 % (R4.1).
- `kStabil(ansaetze: readonly StabilZeile[], uEc: Hundertstel, kGeaendertAm: Date): boolean` mit `StabilZeile = { begonnenAm; kontrolle?; ecSollIst?; unsicher; datenart; istStation; storniert; abgebrochen }` (R4.7): die drei jüngsten gültigen Neuansätze nach der letzten k-Änderung, nur `echt`, ohne Stationen, alle mit |Kontrolle − ECSoll_ist| ≤ max(0.10, u_EC); ein Ansatz ohne Kontrollmessung oder mit «unsicher» bricht die Folge (A13).
- `teilDosis(e: { kQuellen: readonly KQuelle[]; kStabil: boolean; istStation: boolean; zielbereichKlasseD: boolean }): 75 | 85 | 100` (R4.7, Konzept 9.4): Station → 100; eine Komponente noch `startwert` → 75; sonst stabil und nicht Klasse D → 100; sonst 85 (A14).

### `rechner-nachfuellen.ts`

- `messungFuerRechner(e: { platzId; messungen; ansaetze: readonly AnsatzZeile[] }, jetzt: Date, zeitzone: Zeitzone): { art: 'messung'; messung } | { art: 'neue_messung_noetig'; grund: 'keine' | 'veraltet' | 'nicht_heute' }` (R4.9, R10.3): jüngste Messung des Platzes, die nicht `istVeraltet` ist und am Kalendertag von `jetzt` in Zürich liegt (UC7-AK10).
- `kannenLiter(ganze: number, kanne: number, teilkanne: number): number` → V2 in Hundertsteln l (R4.9).
- `nachfuellen(e: { volumen; nachgefuellt; ec1; ecWasser; zielbereich; k; dosis (Stadium aktuell); dAnsatz (Hundertstel ml/L); istStation; ueberHerstellerdosisBestaetigt }): NachfuellErgebnis` (R4.9, R4.5): V1 = V − V2; ECZiel = Bandmitte nach `zielEc`-Regeln 1 und 3 (A15); d = (ECZiel · V − EC1 · V1 − ECWasser · V2) / (k_wirksam · V2); d ≤ 0 → «nur Wasser»; Grenze 1.5 · D_Ansatz in Hundertsteln ml/L als Ganzzahlvergleich 2 · d_h ≤ 3 · D_Ansatz_h (R4.9), dazu min(5.5, 1.2 · D) nach R4.4 (nur diese mit Bestätigung aufhebbar, A16); über der Grenze d = Grenze und «Ziel nicht ganz erreichbar, erwartete EC …» mit (EC1 · V1 + (ECWasser + k_wirksam · d) · V2) / V. Station: feste Dosis je Liter ohne Formel (R4.5). Ausgabe `dMlL` (Hundertstel), Mengen auf V2 im Verhältnis des Stadiums nach R4.11, Messmittel, `nurWasser`, Hinweise.
- `verduennen(e: { v1; ec1; ecZiel; ecWasser; betriebsvolumen }): { art: 'kein_verduennen_noetig'; liter: 0 } | { art: 'nicht_erreichbar' } | { art: 'wasser'; noetig; liter; gekappt; ecErwartet }` (R4.9): EC1 ≤ ECZiel zuerst, dann ECZiel ≤ ECWasser, beide ohne Division; sonst VWasser = V1 · (EC1 − ECZiel) / (ECZiel − ECWasser), gekappt auf V − V1, erwartete EC (V1 · EC1 + VWasser · ECWasser) / (V1 + VWasser).
- `kratkyNachfuellen(e: { fuellstand: Fuellstand; ecIst; zielbereich; dAnsatz; innenLMm; innenBMm }): { art: 'keine_aufgabe' } | { art: 'nur_wasser'; hoechstensLiter } | { art: 'halbe_konzentration'; dMlL; hoechstensLiter }` (R4.10): `ueber_drittel` → keine Aufgabe; EC über der oberen Grenze → nur Wasser; sonst D_Ansatz / 2 je Liter; höchstens 2.5 cm über der Innenfläche des Gefässmodells, auf 0.1 l (A17).

## Regeln (Abgleich mit `01_fachregeln.md`)

- **R4.1** ECSoll, k_wirksam je Stadium, ECWasser mit Plausibilität und Rückfall 0.50; Grenzen 0.20 bis 0.45 und 20 % nur für den k-Vorschlag.
- **R4.2** inneres Band einschliesslich, Bandmitte, Untergrenze ECWasser + 0.30, «Leitungswasser zu hoch», nie über o, für alle Betriebsarten (RF2 Kratky belüftet ohne Sonderweg).
- **R4.3** Stadium für Anzuchtbox, Station (Tag 15), Einwurzeln (Tag 0 bis 7), Direktsaat (wachstum ab Saattag); «reife» nie.
- **R4.4** Kappung 5.5 ml/L und 1.2 · D für Neuansatz, Restdosis und Nachfüllen; Bestätigung hebt sie auf und setzt `kontrolleFolgetag`; keine negative Menge, keine Komponente auf 0.
- **R4.5** feste Dosis, Kontrollbänder, ohne Teil-Dosis und Skalierung, Nachfüllen mit fester Dosis.
- **R4.7** Teil-Dosis-Stand, Restdosis, kIst, k-Vorschlag, Banner, Stabilität.
- **R4.8** Teilwechsel, «möglicherweise doppelt dosiert» mit der gerundeten Teil-EC (E-F4-9).
- **R4.9** Nachfüllen, Grenze in Hundertsteln ml/L, Verdünnen, «veraltet» über `istVeraltet` (R10.3).
- **R4.10** Kratky belüftet: Neuansatz nach R4.2, Nachfüllen unter einem Drittel.
- **R4.11** Rundung, Messmittel, Aufzüge, Abweichung in EC.
- **R4.12** RF1 bis RF12 und die Referenzdatei.
- **Nicht in diesem Paket:** R4.6 (Abhakliste), R4.13 (Säurebedarf, Sicht `v_saeurebedarf`), R4.14 (pH-Korrektur, UC9-AK7 in I1b-04).
