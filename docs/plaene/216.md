Stand 13.11.2026 · Paket N4 (Entscheid 0025, `pakete.md` I3) · Klasse Routine · Planer Lead (Opus 5.5) · Planfreigabe nicht nötig

## Ziel

Unter «Anlagen» in der Leiste sieht Tim je Anlage auf einen Blick, welche Töpfe jeder Ebene belegt, reserviert oder frei sind und was in den Anzuchtboxen keimt. Ein Tipp auf eine Zeile öffnet das Gefäss, die Box oder bei W die Messmaske. Outdoor bleibt bis zur Dachterrasse 2027 leer mit «Anlage anlegen».

## Datenform

```ts
interface TopfZahlen { belegt: number; reserviert: number; frei: number }
interface SortenAnzahl { sorte: string; anzahl: number }
interface GefaessBelegung extends TopfZahlen {
  code: string;            // «R-2.3»
  kennung: string;         // «2.3»
  loecher: number;         // 0 ohne Deckel (A2) oder ohne Gefäss
  pflanzen: number;        // aktive Pflanzungen am Platz
  ohneGefaess: boolean;
  sorten: SortenAnzahl[];
  badge?: string;          // statusBadge(): «nicht geprüft», «Volumen offen», «ruht»
  punkte: ('belegt' | 'reserviert' | 'frei')[]; // je Loch in Lochfolge
}
interface EbeneBelegung extends TopfZahlen { titel: string; ebene?: number; gefaesse: GefaessBelegung[] }
interface BoxBelegung { code; kennung; typ: 'hell' | 'dunkel'; belegt: number; platzzahl: number; sorten: SortenAnzahl[] }
interface AnlagenBelegung extends TopfZahlen { ebenen; boxen; messstellen: { code; kennung }[] }
```
