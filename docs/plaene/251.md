# Plan 251: Testdatei-Wächter ab aktuellem main

Stand 19.11.2026 · Paket RB2 (Nachbesserung Prüftor, ausserhalb der Summen) · Klasse Routine · Planer Lead (Opus 5.5) · Änderung an einer Sperre (Konzept 12.4): von Tim am 19.11.2026 im Chat bestätigt («Ja, umstellen»)

## Ziel

Der Job `testdatei-waechter` in `.github/workflows/pr.yml` meldet nur noch Commits dieses Pull Requests. Basis ist der aktuelle `main` (erster Elternteil des Merge-Commits, den `actions/checkout` für `pull_request` auscheckt), Spitze der Kopf des Pull Requests (zweiter Elternteil). Die geschützte Liste kommt aus `tests/testentwickler.txt` dieser Basis.

## Anlass

`github.event.pull_request.base.sha` bleibt beim Stand des Anlegens. Ein danach gemergter Pull Request mit Änderung an `tests/testentwickler.txt` (jedes Paket mit Testentwickler) liegt so zwischen Basis und `HEAD` und liess #243 und #247 scheitern, obwohl sie keine Testdatei berührten. Ausweg war jedes Mal ein neuer Zweig.

## Änderung

- `BASIS`/`SPITZE` aus `HEAD^1`/`HEAD^2`, wenn `HEAD` ein Merge-Commit ist; sonst wie bisher `pull_request.base.sha` bis `HEAD` (A).
- Prüflogik (geschützte Liste, `Tests:`-Commits, Label `tests-freigegeben`) unverändert.
