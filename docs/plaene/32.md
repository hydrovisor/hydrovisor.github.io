## Regeln

- **R5.5 Push-Zeit** 05:00 bis 22:00 (Grenzen eingeschlossen), Format `hh:mm`; sonst «Push-Zeit nur 05:00 bis 22:00». Vorlauf n 0 bis 14 Tage (Check der Tabelle).
- **R4.4 Kanne** 1 bis 12 l in 0.1-l-Schritten; beim Ändern das Rechenbeispiel «2.3 halbe Dosis je Kanne: vorher x ml, neu y ml» mit x = ½ · D · Kanne_alt, y = ½ · D · Kanne_neu, D = Gesamtdosis des Stadiums Wachstum 3.6 ml/L (A1), Mengen auf 0.5 ml.
- **R4.1 k-Satz:** k_wirksam = Σ k_i · a_i mit a_i aus Wachstum 1.8 : 1.2 : 0.6 (A2); ausserhalb 0.2 bis 0.45 → «nicht übernehmbar»; |k_wirksam neu − bisher| / bisher > 20 % → Rückfrage «k ändert sich um x %. Übernehmen?»; je k_i 0 < k < 1 (Check der Tabelle). Neue Zeilen in `k_faktor` je geänderter Komponente mit `quelle = 'becherversuch'` (A3), `gilt_ab = jetzt`.
- **Messgerät** u_EC 0 bis 1 (drei Dezimalen), u_pH 0 bis 1 (zwei Dezimalen).
- **Ruhe je Gefäss:** Ereignis `ruhe {gesetzt: true|false}` am Gefäss über `schreiben()`; Anzeige aus `v_gefaess_status` («ruht»).
- **Telefonnummer** nur in `einstellung.telefon_vertretung`; nie in Tests, Fixtures oder Code (Annahme 12); Tests verwenden einen Platzhaltertext ohne Ziffernfolge.
- **Notfallblatt** je aktivem Gefäss der Anlage: Kennung, Betriebsart, Zielbereich aus `v_zielbereich` (sonst «–»), Dosis je Kanne aus dem letzten gültigen Neuansatz (Σ ist_ml je Komponente / Volumen · Kanne, auf 0.5 ml, keine Komponente auf 0; A4), letzte Messung (pH, EC, °C, Datum), nächster Wechsel aus `naechster_wechsel_am`, sonst letzter Neuansatz + `intervall_wechseln_d` (Kratky ohne Intervall «–»). Vertretungsblatt: vier feste Sätze aus Konzept 11.7 und die Telefonnummer aus der Datenbank (ohne Nummer: «Telefonnummer in den Einstellungen eintragen»).
- **Gerät neu:** Schritte aus Konzept 11.7 als Markdown im Repository; Einstieg öffnet die Datei auf GitHub.

## Risiken

| Risiko | Folge | Gegenmassnahme |

## Nicht-Ziele

## Annahmen (A)

1. Rechenbeispiel der Kanne mit D = 3.6 ml/L (Stadium Wachstum, Düngeplan V1.6), «halbe Dosis» = ½ · D · Kanne.
2. Anteile a_i für k_wirksam aus Wachstum 1.8 : 1.2 : 0.6 (der Rechner I1b-03 übernimmt später das Verhältnis des Stadiums).
3. Von Hand eingetragenes k gilt als Ergebnis des Becherversuchs (`quelle = 'becherversuch'`).
4. Dosis je Kanne auf dem Notfallblatt aus dem letzten gültigen Neuansatz des Gefässes, bis der Rechner sie liefert.
5. Ruhe je Gefäss nur für Gefässe (nicht Anzuchtboxen und W).
