## Regeln

- **R5.5 Push-Zeit** 05:00 bis 22:00 (Grenzen eingeschlossen), Format `hh:mm`; sonst «Push-Zeit nur 05:00 bis 22:00». Vorlauf n 0 bis 14 Tage (Check der Tabelle).
- **R4.4 Kanne** 1 bis 12 l in 0.1-l-Schritten; beim Ändern das Rechenbeispiel «2.3 halbe Dosis je Kanne: vorher x ml, neu y ml» mit x = ½ · D · Kanne_alt, y = ½ · D · Kanne_neu, D = Gesamtdosis des Stadiums Wachstum 3.6 ml/L (A1), Mengen auf 0.5 ml.
- **R4.1 k-Satz:** k_wirksam = Σ k_i · a_i mit a_i aus Wachstum 1.8 : 1.2 : 0.6 (A2); ausserhalb 0.2 bis 0.45 → «nicht übernehmbar»; |k_wirksam neu − bisher| / bisher > 20 % → Rückfrage «k ändert sich um x %. Übernehmen?»; je k_i 0 < k < 1 (Check der Tabelle). Neue Zeilen in `k_faktor` je geänderter Komponente mit `quelle = 'becherversuch'` (A3), `gilt_ab = jetzt`.
- **Messgerät** u_EC 0 bis 1 (drei Dezimalen), u_pH 0 bis 1 (zwei Dezimalen).
- **Ruhe je Gefäss:** Ereignis `ruhe {gesetzt: true|false}` am Gefäss über `schreiben()`; Anzeige aus `v_gefaess_status` («ruht»).
- **Telefonnummer** nur in `einstellung.telefon_vertretung`; nie in Tests, Fixtures oder Code (Annahme 12); Tests verwenden einen Platzhaltertext ohne Ziffernfolge.
- **Notfallblatt** je aktivem Gefäss der Anlage: Kennung, Betriebsart, Zielbereich aus `v_zielbereich` (sonst «–»), Dosis je Kanne aus dem letzten gültigen Neuansatz (Σ ist_ml je Komponente / Volumen · Kanne, auf 0.5 ml, keine Komponente auf 0; A4), letzte Messung (pH, EC, °C, Datum), nächster Wechsel aus `naechster_wechsel_am`, sonst letzter Neuansatz + `intervall_wechseln_d` (Kratky ohne Intervall «–»). Vertretungsblatt: vier feste Sätze aus Konzept 11.7 und die Telefonnummer aus der Datenbank (ohne Nummer: «Telefonnummer in den Einstellungen eintragen»).
- **Gerät neu:** Schritte aus Konzept 11.7 als Markdown im Repository; Einstieg öffnet die Datei auf GitHub.

## Umsetzung und Runde 1 (6.11.2026)

Abweichungen vom Kurzplan:
- `einstellungAus` ist entfallen; die Maske liest die Zeile direkt. Dazugekommen sind `kVorgang`, `ruheVorgang` und `kHerkunftAus`.
- `src/ui/einstellungen.css` statt `notfallblatt.css`; das Notfallblatt nutzt nur `hv-druck*` und `hv-blatt*` aus dem Design System.
- Der Rückfragetext lautet «k ändert sich um x % gegen bisher. Übernehmen?».
- Das Vertretungsblatt hat drei feste Regeln plus eine Kontaktzeile.

Prüfer `pruefer` Runde 1: «nachbessern», 11 Befunde, alle umgesetzt:
1. Die Telefonnummer ist erst nach erfolgreichem Lesen speicherbar. Schlägt das Lesen fehl, bleiben Feld und Knopf gesperrt, mit dem Hinweis «Nur mit Netz lesbar, Seite neu laden». Ein leeres Feld kann die gespeicherte Nummer so nicht mehr überschreiben.
2. `lesen` hat einen eigenen Ergebnistyp (`gelesen` / `nicht_gelesen`) und einen eigenen Lesetext. Das Notfallblatt meldet einen Lesefehler in der Steuerung, die nicht gedruckt wird.
3. Unit-Tests für den Schreibweg: `tests/unit/einstellungen-schreiben.test.ts`.
4. k je Komponente zeigt «gültig ab» und Quelle (`kHerkunftAus`).
5. Die Komponenten sind nach `produkt_id` sortiert (Micro, Grow, Bloom), auch mit den echten Produktnamen.
6. Die Dosis je Kanne wird ungerundet aus den Positionen gerechnet und erst am Schluss auf 0.5 ml gerundet. Eine dosierte Komponente zeigt mindestens 0.5 ml, eine nicht dosierte entfällt.
7. Die Reihenfolge folgt `anlage.laufweg`, übrige Gefässe kommen danach nach Code. (A) Der Laufweg enthält Kennungen.
8. «über 20 %» wird ungerundet in Millionsteln verglichen.
9. Messmittel haben höchstens eine Dezimale.
10. Die Beschriftungen heissen «Einstellungen öffnen» und «Ruhe aufheben».
11. Der Plan ist mit diesem Abschnitt nachgeführt.

## Runde 2 (6.11.2026)

Prüfer `pruefer`: «nachbessern», 5 Befunde, alle umgesetzt:
1. k je Komponente mit höchstens drei Dezimalen, wie die Spalte `numeric(4,3)`. k_wirksam wird exakt als Ganzzahl gerechnet (n6 = 3·g + 2·m + b = 6000 · k_wirksam). Damit lösen genau 20 % keine Rückfrage aus, und 0.450167 liegt über der Grenze.
2. Das Telefonfeld ist bis zum erfolgreichen Lesen gesperrt; `telefonSpeichern` prüft selbst, ob gelesen wurde.
3. Das Notfallblatt sperrt «Drucken», solange die Telefonnummer nicht gelesen ist.
4. Dosis je Kanne aus dem letzten gültigen Neuansatz **oder Teilwechsel**, wie in der Maske «Gefäss» und im Bündel-Zuschnitt (Plan 20). Abweichung von A4 mit Grund: Nach einem Teilwechsel gilt dessen Dosis.
5. Das Bündel behält je Ort zusätzlich den letzten Neuansatz, weil «Lösung wechseln» ab dem letzten Neuansatz rechnet (Konzept, Auslöser-Tabelle). So zeigt das Blatt den nächsten Wechsel auch nach einem Teilwechsel.
